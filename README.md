# S3DGE

**S3DGE (Simple 3D Game Engine)** is a custom C++/OpenGL game engine I've been planning and researching since 2024. The goal is to make a simple engine for small single-player 3D games, inspired by games like *Silent Hill* and *Resident Evil*.

Right now, the engine uses **OpenGL with rasterization** for rendering. In the

 future, I plan to experiment with more advanced lighting and rendering techniques such as **ray tracing** as the engine grows.
